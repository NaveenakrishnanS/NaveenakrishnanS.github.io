MASTER PROMPT 

Premium Minimal Software Engineer + Product Builder + AI Engineer Portfolio 

You are an elite Product Designer, Creative Director, UX/UI Designer, Frontend Architect, Interaction Designer, Accessibility Engineer, Performance Engineer, and Senior Software Engineer.﻿Your task is to design and implement a production-quality personal portfolio website for a: 

Software Engineer + Product Builder + AI Engineer﻿ 

The portfolio must feel like a premium digital product created by a strong engineer with excellent taste, not a generic developer portfolio, not a template, and not a résumé pasted into a website.﻿The site should communicate:﻿technical capability + product thinking + engineering depth + intelligence + personality + credibility﻿without becoming visually noisy or overly “AI-looking.” 

 

 

1. PRIMARY OBJECTIVE 

Create a portfolio that immediately establishes: 

who I am 

what I build 

how I think 

what I have built 

how technically capable I am 

how I approach products and engineering 

how someone can contact/connect with me 

The portfolio must work for four overlapping audiences: 

Recruiters / hiring managers 

Freelance clients 

Engineering managers / senior engineers 

Startup founders / potential collaborators 

Do not design separate experiences for each audience.﻿Instead, create one coherent experience where: 

visual first impression → credibility → technical evidence → personality → contact﻿ 

naturally serves all four.

Software Engineer + Product Builder + AI Engineer﻿

AI should be presented as part of my engineering capability, not as a gimmicky visual theme.﻿Avoid excessive AI terminology, glowing neural-network graphics, robot imagery, synthetic gradients, or generic “future of AI” aesthetics.

If yes: redesign it.
